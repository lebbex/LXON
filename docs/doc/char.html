Definition

A char value allows for storing explicitly single character strings.

Syntax

A char requires a single quote ' at the start, as type declaration. The following character is treated as the full contents of the value (or char if the language supports it).

Escaping

Chars require !! other.escape ! escape characters ! for the following characters:

  • Newline \n
  • Carriage Return \r
  • Backslash \\
  • Null Byte \0 *Represents an empty character

Important

The char value ends after the first character, so trailing single quotes don't acctually close the string, they announces the start of a new string character, similarly to the caret symbol ^ for !! values.text.string ! string ! values.

Although it's supported to type a litteral space or tab character following the single quote to set the value to such, it is standardized to use the !! other.escape ! escape character ! alternative of the whitespace (such as \s and \t respectively). This makes it more visible and safe.
