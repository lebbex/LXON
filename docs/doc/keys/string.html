Definition

String keys are !! key.typed ! typed keys ! that use !! val.text.fullstring ! full strings ! to label values inside !! cont.map ! maps !. However, unlike casual full strings, they're terminated by colons : like !! keys.regular ! regular keys ! are.

String keys are useful in one scenerio and one scenerio only: when an !! cont.obj ! object ! is expected to recieve keys that may contain invalid characters or syntax. This is because !! keys.regular ! regular keys ! (the ones used by objects) do not support !! other.escape ! escape characters !.

For instance, if an object's keys may begin with a tab character, or contain a newline or colon, it would be dangerous to serialize the object directly. It would either return an error, or in less friendly parsers, it might even just create corrupted data. In that case, it would be critical to use !! cont.maps ! maps ! with string keys.

Syntax

To write a string key, first, ensure the !! cont.map ! map ! is set to use string keys. Do so by writing the declaration character after the open parenthesis, a double quote ".

Your string key type declaration should look as follows: 

("

Afterwards, write each key without declaring the type as it has already been declared. Terminate the key using a colon :. Use the !! other.escape ! escape character ! only for the following characters inside the key:

  • Colon \:
  • Newline \n
  • Carriage Return \r
  • Backslash \\

You don't need to escape backticks ` or carets ^ because the parser is only expecting the colon as termination symbol for the key, backticks and carets are already parsed litterally for string keys.

Important

If the first character of the key is a tab or a space, you MUST !! other.escape ! escape ! it using the \t and \s codes respectively. Also, although tabs are supported within the key, it is standardized to replace them with \t. This allows for better visualization as well as a shortening of the visual length of the string. This does however come at the cost of an extra byte stored per tab, so this decision comes down to the developper.

Usage

Here's some example usage of string keys as reference (the !! cont.root ! root container ! is a map with string typed keys): 

("
key: "value
\:colon: $
newline\n: -.342
`backtick: &26
^caret: @keybind
\s  key: #e52074
\t \t k: =e2819c
