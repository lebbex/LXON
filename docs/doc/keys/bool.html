Definition

Boolean keys are typed keys that use !! val.bool ! booleans ! to label values inside !! cont.map ! maps !.

They are some of the least useful key types, supporting an astonishing 2 keys. This makes it useless in almost any scenerio. However, since they could be implemented, they were implemented.

If you end up needing to use boolean keys, please email lxon@lebbex.com because I'm geniuenly curious what your use case is.

Syntax

To write a boolean key, first, ensure the !! cont.map ! map ! is set to use the bool key type. Do so by typing the bool key type declaration character directly following the open parenthesis, a colon :.

Your boolean key type declaration should look as follows (yes it looks like a smiley face): 

(:

Afterwards, write each key as simple $ for true and ! for false. Unlike the other !! keys.typed ! typed keys ! in !! cont.map ! maps !, you do not need to terminate the key using a colon :, as the key itself can only be a single character long. This saves up on a byte of storage.

Usage

Here's some example usage of boolean keys as reference (all maps have the same data): 

{
pretty: (:
	$: "value
	!: 400

clean: (:
	$ "value1
	! 400

small: (:
	$"value1
	!400
