Definition

Text key types are keys that use regular text for their keys. They are often used in maps to alow for keys that aren't supported by !! keys.reg ! object keys ! or !! keys.char ! doodad keys !.

If dynamically constructing an object with dynamic keys that may differ, you should always use maps with !! keys.text.string ! string keys !, or !! keys.text.char ! char keys ! in the event of every key being 1 character long exactly.

Here are both text key type's declaration characters:

  • String " or ` (Expansion from !! cont.obj ! objects !)
  • Character ' (Expansion from objects or !! cont.doo ! doodads !)

Text keys get turned into string by default, unless the language or environment supports a dinstinct single-character string value type (char).

Usage

Here's some example usage of text keys as reference: 

{
string map: ("
	key: "value
	\:key: $
	key\n: -.342

char map: ('
	k: "value
	\:: $
	\n: -.342
	!: "all keys are litteral chars
