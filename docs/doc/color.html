Definition

A color type is a color value's precision and color space (which can be linear).

The color's !! val.col.precision ! precision ! defines how many bits a color is stored in, which, in the case of !! val.col.prec.float ! float !, can be infinite.

The color's !! val.col.space ! space ! defines how the color should be interpreted, organized and reproduced. Different color spaces hold different color gamuts, with varying widths and utilities.

  • !! val.color.prec.8 ! 8 Bit Colors !:
    • sRGB Color #
    • Linear sRGB Color =
    • Preset Color / with .
    • Linear Preset Color / with -
  • !! val.color.prec.10 ! 10 Bit Colors !:
    • Preset Color / with ,
    • Linear Preset Color / with <
  • !! val.color.prec.12 ! 12 Bit Colors !:
    • Preset Color / with :
    • Linear Preset Color / with >
  • !! val.color.prec.16 ! 16 Bit Colors !:
    • sRGB Color ;
    • Linear sRGB Color ;=
    • Preset Color / with ;
    • Linear Preset Color / with =
  • !! val.color.prec.float ! Infinite Precision Colors !:
    • Preset Color / with '
    • Preset Linear Color / with ^

Most languages and environments don't have implementations for all these value types. Many don't even have implementations for the sRGB color types. To make up for it, LXON parsers/serializers often have custom objects that hold the color types.

For example, in JavaScript, there are sRGB colors, which have a "linear" and "deep" boolean, on top of a float for each channel. There are also preset color objects and custom color objects, all containing color, precision and color space data.

Distinction

This documentation won't go into depth on the difference between all color spaces.

If you never had to ask yourself which colorspace you're using, then you're most likely using 8 bit sRGB, and can confidently use that color type for your implementation. It's what's used for web, photography, user interfaces, and countless other usecases and industries. It is wise however to look into virtual color theory.

As to the difference between 8 bit, 10 bit, 12 bit, 16 bit and infinite float precision, the difference is only a question of what's necessary for your implementation. Gnerally, 8 bit is what's used by most programs and systems. The only time you'll ever need to use a higher definition color representation is when you explicitly know the difference and this section of documentation is obsolete to you.
