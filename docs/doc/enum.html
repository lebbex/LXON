Definition

An enum is a value type which can hold an optional enum type and a required enum member. This allows for storing enums under text, which can be read and understood (as opposed to storing them under numbers), and can be distinguished from regular string.

Syntax

An enum requires the asterisk symbol * as type declaration. If the first character following that is another asterisk, then the enum type becomes undefined. Otherwise, everything until the first colon gets parsed into the enum type. The enum's type does not support !! other.escape ! escape sequences !.

After reading or skipping the enum type, the enum member is parsed. Every following character is treated as the contents of the enum member, until the first instance of either its terminator symbol (backtick), or another valid declaration character as show below:

  • Backtick ` (terminator symbol)
  • Caret ^ (!! val.text.string ! string ! declaration)
  • Asterisk * (!! val.enum ! enum ! declaration)

It is standardized however to use the backtick, and only use the other characters for !! val.enum.chain ! chaining ! other values after it. Like with full strings, enum members also ends at the end of the line, so trailing backticks aren't strictly required.

Chaining

Enums can be chained easily, a feature which makes use of the rare characters which are unexpected to be present in a keybind, such as those stated above. These characters happen to be declaration characters for other types.

In order to make use of them, and save up on valuable space and syntax, typing one of those characters in an enum member terminates the enum and declares the next value as having the type declared by the termination character.

These chains should only ever be made inside an !! containers.arr ! array !, as it is the only event where values are expected to follow eachother.

Here's some examples of enum chaining in action: 

{
enums:[ **gun **sword **grande

enum+str1:[ **foo` `string`
enum+str2:[ **foo ^string`

Escaping

As a consequence of its increase in complexity, enum members require !! other.escape ! escape sequences ! for the following characters:

  • Newline \n
  • Carriage Return \r
  • Backslash \\
  • Backtick \`
  • Caret \^
  • Asterisk \*

Here's some example usage of keybind escaping: 

{
enum1: *newline:Element\n

enum2: *songs:sweatpants \\ easy access

enum3: *operator:\*

Whitespace

Although tab representation is supported, it is standardized to replace them with \t. This allows for better visualization as well as a shortening of the visual length of the enum. This does however come at the cost of an extra byte stored per tab, so this decision comes down to the developper.

Enums trim all trailing whitespace if terminated by the end of the line. Counter this by either using a terminator symbol, or replacing the last whitespace with its escape code (\s for space and \t for tab).

Usage

Here's some example usage of enum values as reference: 

{
perms: *perm:admin
theme: **dark

inventory:[ *weapon:sword` *weapon:gun *food:bread

enum-string1:[ **dev` `Carlos
enum-string2:[ **dev ^Nick Jasper\s

game: *game:arrel`
