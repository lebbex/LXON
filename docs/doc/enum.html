Definition

An enum is a value type which can hold an optional enum type and a required enum member. This allows for storing enums under text, which can be read and understood (as opposed to storing them under numbers), and can be distinguished from regular string.

Syntax

An enum requires the asterisk symbol * as type declaration. If the first character following that is another asterisk, then the enum type becomes undefined. Otherwise, everything until the first colon gets parsed into the enum type.

After reading or skipping the enum type, the enum member is parsed. Every following character is treated as the contents of the enum member, until the first instance of a terminator symbol:

  • Backtick ` (terminates)
  • Caret ^ (terminates and declares !! val.text.string ! string !)

Enum members also ends at the end of the line, so trailing backticks aren't strictly required. This does however trim all trailing whitespace, as with all other value types terminated by end of line.

Neither the enum types nor members support !! other.escape ! escape sequences !.

Usage

Here's some example usage of enum values as reference: 

{
perms: *perm:admin
theme: **dark

inventory:[ *weapon:sword` *weapon:gun` *food:bread

enum-string1:[ **dev` `Carlos
enum-string2:[ **dev ^Nick Jasper

game: *game:arrel`
