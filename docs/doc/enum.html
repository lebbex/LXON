Definition

A enum is a value type which can hold an optional enum type and a required enum member. This allows for storing enums under text, which can be read and understood (as opposed to storing them under numbers), and can be distinguished from regular string.

Syntax

A enum requires the asterisk symbol * as type declaration. If the first character following that is another asterisk, then the enum type becomes undefined. Otherwise, everything until the first colon gets parsed into the enum type.

After reading or skipping the enum type, the enum member is parsed. Everything until the end of the line or the first terminator symbol gets parsed into the enum member. Here's a list of all terminator symbols for the enum member:

  • Backtick `
  • Caret ^
  • At Symbol @
  • Asterisk *
  • Question Mark ?

It is standardized however to use the backtick, and only use the other characters for !! val.enum.chain ! chaining ! other values after it. Like with full strings, enum members also ends at the end of the line, so trailing backticks aren't strictly required. Enum members also support trailing whitespace such as tabs or space characters.

As a consequence of its increase in complexity, enum members require escape sequences for the following characters:

  • Newline \n
  • Carriage Return \r
  • Backslash \\
  • Backtick \`
  • Caret \^
  • At Symbol \@
  • Asterisk \*
  • Question Mark \?

Chaining

Enums can be chained easily. However, these chains should only ever be done inside an !! containers.arr ! array !. Here's all the possible chained values:

  • When a caret ^ is used to terminate an enum member, it will not only mark the end of the current enum but also the start of a new !! val.text.str ! string !.
  • When a at symbol @ is used to terminate an enum member, it will mark the end of the current enum and the start of a !! val.keybind ! keybind !.
  • When a asterik * is used to terminate an enum member, it will mark the end of the current enum and the start of a new one.
  • When a question mark ? is used to terminate an enum member, it will mark the end of the current enum and the start of a !! val.binary ! binary ! value.

Important

Although tab representation is supported, it is standardized to replace them with \t. This allows for better visualization as well as a shortening of the visual length of the keybind. This does however come at the cost of an extra byte stored per tab, so this decision comes down to the developper.

Also, although trailing whitespace is supported, if there's no trailing backtick, it is standardized to replace the last character with a \s if it's a space, or a \t if it's a tab. Otherwise, it's easy to miss the trailing whitespace and be unclear as to whether it was intentionally done or not. For this reason, it is very possible for a friendly parser to trim leading whitespace, assuming it's a typing mistake.
