Definition

A raw string is the simplest way of representing a string in LXON. It doesn't allow for !! other.escape ! escape characters !, which is what makes it so simple, but also limits it heavily for many use cases.

The only use case for a raw string is for a single-line string with no trailing whitespace. This makes it perfect for usernames, titles, email addresses, URLs, file names and paths, IDs, tags, labels, version numbers, country codes, etc.

Syntax

A raw string requires a double quote " at the start as a type declaration. The entire rest of the line will be read verbatim as the string, ignoring all !! other.escape ! escape sequences !.

The only way to end a raw string is with a newline or end of file. This means raw strings are not to be used for inline data unless it's the last element of the line.

All trailing whitespace is removed. This ensures no accidental, invisible input makes its way into the data content. To represent a string with trailing whitespace, use a !! val.text.str ! regular string ! instead.
