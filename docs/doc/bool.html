Definition

A boolean is a value with two states, like a singular bit is. It can be either true of false. This true/false combination can be used in many instances to store any binary state, such as:

  • Yes / No
  • On / Off
  • Positive / Negative
  • Enabled / Disabled
  • Online / Offline
  • DarkMode / LightMode
  • Male / Female (No political comments being made)

Syntax

A boolean is a !! val.static ! static value !. This means it doesn't acctually require any data to be stored. It only requires the declaration character, that is either $ for true or ! for false. Once the parser reads this declaration character, it instantly completes the value.

Important

After writing true $, make sure the next character is either a space, a newline or another bool symbol (dollar sign or exclamation point). Otherwise, the parser will consider the dollar symbol as a type declaration for a !! val.mon ! monetary value !.

Do the same for false ! as it simplifies the mental load and exclamation points may someday become a dual-declaration type like the dollar sign is. Failure to keep a space or newline after the exclamation point may cause later parsers to misparse old data that doesn't follow this rule.

Visualization

A simple trick to remember the characters for booleans is to think of money. When you think about it, it becomes really obvious.

True $$$

The value true is generally regarded as the presence of something. For example, "online = true" means the presence of the online status. Even "offline = true" means the presence of the offline status. No matter how you look at it, true means the presence of something.

Hence, when thinking of money, true is the presence of money. And what character best symbolizes that? The dollar sign $.

False !!!

The value false, by consequence, is generally regarded as the lack of something. A status or a truth in a statement. For example, "online = false" means the absence of the online status, the lack of truth in the statement that the user is online.

Hence, when thinking of money, false is the absence of money. And when lacking money, you yell. You scream. You feel this terrible feeling, that best gets incapsulated by the exclamation symbol !.

Usage

  • If the value has only two states, use a boolean.
  • If the value has more then two states (Low, Medium, High), use !! val.enum ! enums ! instead.
  • If the value has two main states, as well as alternative states, you can use booleans and different value types such as !! val.text.raw ! raw strings !, !! val.static ! static values !, !! val.special ! special values !, etc. This however requires a bit more code on the interpreter.
