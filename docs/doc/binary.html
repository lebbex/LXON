Definition

A binary value is a value type which can hold binary data of any length. It stores it under hexadecimal, allowing optional spaces for formatting.

Syntax

A binary value requires the question mark ? as type declaration. Every following hexadecimal character is treated as the binary contents. The first non-hexadecimal character marks the end of the binary value, and the parser begins parsing the next key or value at the offending character.

It is standardized however to use the backtick, and only use non alpha-numeric characters for chaining other values after it. Binary values also ends at the end of the line, so trailing backticks aren't strictly required.

Usage

Here's some example usage of binary values as reference:

count: ?0123 4567 89ab cdef

bin-keybind:[ ?ffff@Mouse Left

bind-enum:[ ?0102*enum:member

bind-string:[ ?ffff^string
