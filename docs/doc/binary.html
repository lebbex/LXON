Definition

A binary value is a value type which can hold binary data of any length. It stores it under hexadecimal, allowing optional spaces for formatting.

Syntax

A binary value requires the question mark ? as type declaration. Every following hexadecimal character is treated as the binary contents. The first non-hexadecimal character marks the end of the binary value, and the parser begins parsing the next key or value at the offending character.

It is standardized however to use the backtick, and only use non alpha-numeric characters for !! val.binary.chain ! chaining ! other values after it. Like with full strings, binary values also ends at the end of the line, so trailing backticks aren't strictly required.

Chaining

Binary can be chained easily. However, these chains should only ever be done inside an !! containers.arr ! array !. Here's all the possible chained values:

  • When a caret ^ is used to terminate a binary value, it will not only mark the end of the current binary value but also the start of a new !! val.text.str ! string !.
  • When a at symbol @ is used to terminate a binary value, it will mark the end of the current binary value and the start of a !! val.keybind ! keybind !.
  • When a asterik * is used to terminate a binary value, it will mark the end of the current binary value and the start of a !! val.enum ! enum !.
  • When a question mark ? is used to terminate a binary value, it will mark the end of the current binary value and the start of a new one.
