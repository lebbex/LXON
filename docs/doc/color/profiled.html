Definition

Profiled color is the solution to infinite color space and precision support. It allows for the storage of not only the color, but the space, transfer function (regular or linear), and precision level. As such, colors don't need to be stored in complex !! containers.objects ! objects ! or !! containers.doodads ! doodads !, with non-standardized formats.

Syntax

Profiled color type declarations have three components: [/][code][terminator]

The first is the initial type declarator /. This tells the parser that the following value (or key type) is a profiled color. The parser then reads what's after as the !! val.col.spaces.profiles.code ! color space code !. Finally, once it reaches a !! val.col.spaces.prof.terminator ! terminator symbol !, it ends the declaration type and reads the next value (or following !! keys.typed ! typed keys !) with the color profile loaded.

Codes

Color codes dictate the color space. There are !! val.col.spaces.prof.prim ! standardized color codes !, the recommended color codes to use, and !! val.col.spaces.prof.custom ! custom color codes ! for more complex use cases.

Primary (Standardized)

Primary color space codes are codes composed of one or no characters. They are the most used color space codes.

  • Display P3 *Empty color code, straight to the terminator
  • ACES2065-1 (AP0) 0
  • ACEScg (AP1) 1
  • ACEScct 7
  • ACEScc 6
  • Adobe RGB #
  • DCI-P3 3
  • ProPhoto 9
  • Rec. 2020 2
  • Rec. 709 8
  • Wildcard (unidentified) ?

Custom

Custom color codes are 2+ character long codes starting with a letter that aren't already used by any secondary codes (see above). They don't resolve to anything, and must be interpreted after the fact. It is generally considered bad practice, although for internal use cases it is fully understandable.

If any 2 character code gets popularized enough, it can be officially standardized and resolved to a specific color space in future editions of the parser. For standardization request submissions of 2 character codes (must start with a letter), contact lxon@lebbex.com.

Terminators

To terminate a profiled color type declaration, you must use a specific symbol that also indicates the precision level and whether or not it's a linear edition of the color space.

Regular

Regular profiled color is the intended color space in its default form, with the computed curvature taken into account. It's the most often used color profile EOTF.

  • !! val.col.prec.8 ! 8 Bit ! / with .
  • !! val.col.prec.10 ! 10 Bit ! / with ,
  • !! val.col.prec.12 ! 12 Bit ! / with :
  • !! val.col.prec.16 ! 16 Bit ! / with ;
  • !! val.col.prec.float ! Infinite (Float) ! / with '

Linear

Linear profiled color is the color space in its linear form, with a linear EOTF applied. This makes it optimal for performing calculations on, however it does require a conversion back to its regular form before displaying.

  • !! val.col.prec.8 ! 8 Bit ! / with -
  • !! val.col.prec.10 ! 10 Bit ! / with <
  • !! val.col.prec.12 ! 12 Bit ! / with >
  • !! val.col.prec.16 ! 16 Bit ! / with =
  • !! val.col.prec.float ! Infinite (Float) ! / with ^
