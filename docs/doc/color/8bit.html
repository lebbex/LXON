Definition

An 8 bit color value is the simplest and most common way of storing a color. It allows for storing colors with an 8 bit depth per channel, totalling 4 bytes (32 bits) over 4 channels (red, green, blue, alpha/opacity).

This group supports all 3 color spaces:

  • sRGB Color #
  • Linear Color =
  • Profiled Color (Regular) / with .
  • Profiled Color (Linear) / with -

Syntax

Following the type declaration (see above), all succeeding hexadecimal characters (0 to 9 and "a" through "f") are used to store the color data.

The first two characters converge into the red channel, where "00" gets read as the full lack of red and "ff" reads as the full presence of red. The next two characters converge into the green channel, following the same rules as the red, and the next two become the blue channel. The final character pair converges into the alpha channel, also known as opacity.

Spaces cannot be used inside of colors, as they will simply terminate them. Also, channels can be skipped using underscores _. !! val.col.prec.8bit.skip ! View channel skipping. !

Termination

The color is terminated at the first non-hexadecimal character following a channel.

The terminating symbol of a color (any non-hexadecimal character) isn't skipped and is parsed as the start of a new key or value. It is generally good practice to always end a color value by either a space or a newline.

Termination cannot happen within a channel. Once you begin writing a channel, you must write the full channel or face a potential parsing error.

Examples of proper and improper color termination (read comments): 

{
sRGB: #00112233
Linear: =00112233
P3: /00112233

# Color bleeding into key (bad) -- here the color is acctually =ffffaaa2
aaa1: =ffffaaa2: "value

# Color terminated by the next key (okay)
rrr1: =2e57rrr2: "value

# Color not bleeding into key (recommended)
aaa3: =ffff aaa4: "value

# Color terminated by the next string
array:[ =0000`string`

Channel Skipping

If a certain channel's first hexadecimal character isn't present, the parsing of the color ceases and the current color returns, setting the remaining channels to their default values (red: 0%, green: 0%, blue: 0%, alpha: 100%).

Also, if a certain channel's first character is an underscore, the parsing of that channel gets skipped, setting the channel's value to it's default value (see above), and the parsing of the next happens.

As consequence, if a color happens to have an empty color channel, writing of that data can be skipped. This can be very useful to save characters, especially for skipping the alpha channel which is usually 100% opaque either way.

Channel skipping examples (the keys are named after the colors): 

{
black: #
red: #ff
orange: =ff70
yellow: /vg.ffff
green: #_ff
