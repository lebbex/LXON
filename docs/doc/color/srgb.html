Definition

Regular

SRGB is likely the most used color space throughout technology, having been created by HP and Microsoft in 1996. It's universally supported, pandering to the lowest common denominator. As consequence, sRGB color has the smallest color range in most if not all other color spaces. It is unable of recreating higher richness colors.

Linear

Color is percieved by the human eye with a curve, where it's very sensitive to dark colors but brighter colors not so much. To make up for it, most color spaces store color modified with a curve. Linear color stores color linearly, without the curve, which cannot be displayed as is but is very practical for math operations.

Syntax

SRGB color is supported in !! val.col.prec.bit8 ! 8 bit precision ! only, in two different color spaces using two different type declarators:

  • Regular SRGB #
  • Linear SRGB =

Following the type declaration (see above), all succeeding hexadecimal characters (0 to 9 and "a" through "f") are used to store the color data.

The first two characters converge into the red channel, where "00" gets read as the full lack of red and "ff" reads as the full presence of red. The next two characters converge into the green channel, following the same rules as the red, and the next two become the blue channel. The final character pair converges into the alpha channel, also known as opacity.

Spaces cannot be used inside of colors, as they will simply terminate them. Also, channels can be skipped using underscores _. !! val.col.prec.8bit.skip ! View channel skipping. !
