Distinction

A color space defines how the color should be interpreted, organized and reproduced. Different color spaces hold different color gamuts, with varying widths and utilities.

LXON supports infinite color spaces. Nevertheless, some are more important than others, the most important being !! val.col.spaces.srgb ! regular sRGB color !. To not burden all colors with complexity, three different major color spaces were created.

Consequently, the most used color space, !! val.col.spaces.srgb ! regular sRGB !, has very simple syntax. Its !! val.col.spaces.lin ! linear alternative ! has almost the same complexity. However, other color spaces are regrouped as !! val.col.spaces.prof ! profiled colors !, which has far more complexity in type declaration than the former two.

Also, most environments dont support all color spaces, only the former two, so seperating them from the other less supported ones allows for implementing them into the native solution, while implementing profiled colors as a custom object.

Finally, seperating the three allows for simpler learning, where one could very comfortably only learn how to read/write sRGB and linear sRGB colors, with its simple syntax, and completely ignore the profiled colors altogether. In many if not most cases, one might only acctually need to learn regular 8 bit sRGB.

Spaces

!! val.col.spaces.srgb ! SRGB Color !

SRGB is likely the most used color space throughout technology, having been created by HP and Microsoft in 1996. It's universally supported, pandering to the lowest common denominator. As consequence, sRGB color has the smallest color range in most if not all other color spaces. It is unable of recreating higher richness colors.

It uses # and ; as type declaration for regular/deep color respectively.

!! val.col.spaces.lin ! Linear SRGB Color !

Color is percieved by the human eye with a curve, where it's very sensitive to dark colors but brighter colors not so much. To make up for it, most color spaces store color modified with a curve. Linear color stores color linearly, without the curve, which cannot be displayed as is but is very practical for math operations.

It uses = and ;= as type declaration for regular/deep color respectively.

Other Color Spaces (!! val.col.spaces.profiles ! Profiled !)

There are many other color spaces supported in LXON. However, since they are less used by far, to save up on type declarators, they all use / as type declarator, alongside with a code respective to the color space and terminator symbol respective to the precision.

View !! val.col.spaces.profile.syntax ! profiled color syntax ! to see more.
