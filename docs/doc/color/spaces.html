SRGB Color

SRGB is likely the most used color space throughout technology, having been created by HP and Microsoft in 1996. It's universally supported, pandering to the lowest common denominator. As consequence, sRGB color has the smallest color range in most if not all other color spaces. It is unable of recreating higher richness colors.

SRGB color is supported in two different precision levels, using two different type declarators:

  • !! val.col.bit8 ! Regular (8 bit) ! #
  • !! val.col.bit16 ! Deep (16 bit) ! ;

Linear SRGB Color

Linear sRGB color functions identically to sRGB color, sometimes being an extension of the type. Color is percieved by the human eye with a curve, where it's very sensitive to dark colors but brighter colors not so much. To make up for it, most color spaces store color modified with a curve. Linear color stores color linearly, without the curve, which cannot be displayed as is but is very practical for math operations.

Linear sRGB color is supported in two different precision levels, using two different type declarators:

  • !! val.col.bit8 ! Regular (8 bit) ! =
  • !! val.col.bit16 ! Deep (16 bit) ! ;=
