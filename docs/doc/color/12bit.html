Definition

A 12 bit color value allows for storing colors with an 12 bit depth per channel, totalling 6 bytes (48 bits) over 4 channels (red, green, blue, alpha/opacity). Each channel is serialized into 3 hexadecimal characters.

This group supports only profiled colors. In the rare event where you want to use sRGB color in 10 bit, use the alternative sRGB code s#.

  • Profiled Color (Regular) / with :
  • Profiled Color (Linear) / with >

Syntax

Following the type declaration (see above), all succeeding hexadecimal characters (0 to 9 and "a" through "f") are used to store the color data.

The first three characters converge into the red channel, where "000" gets read as the full lack of red and "fff" reads as the full presence of red. The next three characters converge into the green channel, following the same rules as the red, and the next three become the blue channel. The final character trio converges into the alpha channel, also known as opacity.

A single space between channels is allowed. Multiple spaces between channels however isn't, as this would complicate parsing and make formatting uglier with no gain.

Also, channels can be skipped using underscores _. !! val.col.prec.12bit.skip ! View channel skipping. !

Termination

The color is terminated at the first non-hexadecimal character following a channel. The first space after a channel doesn't terminate a color, however the second one does.

It is standardized to terminate 12 bit colors using a backtick ` or a newline, as any other character isn't skipped by the parser and is read as the start of the next key or value. This standard makes parsing predictable. It can however be useful for chaining other inline values after the color in a compressed format.

Termination cannot happen within a channel. Once you begin writing a channel, you must write the full channel or face a potential parsing error.

Channel Skipping

If a certain channel's first hexadecimal character isn't present, the parsing of the color ceases and the current color returns, setting the remaining channels to their default values (red: 0%, green: 0%, blue: 0%, alpha: 100%).

Also, if a certain channel's first character is an underscore, the parsing of that channel gets skipped, setting the channel's value to it's default value (see above), and the parsing of the next begins.

As consequence, if a color happens to have an empty color channel, writing of that data can be skipped. This can be very useful to save characters, especially for skipping the alpha channel which is usually 100% opaque either way.

Channel skipping examples (the keys are named after the colors): 

{
black: /#:
red: /s#: fff
orange: /0> fff 700
yellow: /vg:ffffff
