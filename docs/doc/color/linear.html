Definition

Color is percieved by the human eye with a curve, where it's very sensitive to dark colors but brighter colors not so much. To make up for it, most color spaces store color modified with a curve. Linear color stores color linearly, without the curve, which cannot be displayed as is but is very practical for math operations.

Syntax

SRGB color is supported in two different precision levels, using two different type declarators:

  • !! val.col.prec.bit8 ! Regular (8 bit) ! =
  • !! val.col.prec.bit16 ! Deep (16 bit) ! ;=

View !! val.col.prec.bit8.syntax ! 8 bit syntax ! to write basic linear sRGB color.(Recommended)

View !! val.col.prec.bit16.syntax ! 16 bit syntax ! to write deep linear sRGB color.
