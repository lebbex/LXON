Definition

Date keys are !! key.typed ! typed keys ! that use !! val.date ! dates ! to label values inside !! cont.map ! maps !.

Syntax

To write a date key, first, ensure the !! cont.map ! map ! is set to use date keys. Do so by writing the declaration character after the open parenthesis, an ampersand &.

Your date key type declaration should look as follows: 

(&

Afterwards, write each key as a valid date, terminating the key with a double colons :: before writing the value associated to the key.

View !! val.date ! date value syntax ! to see how to write valid dates in LXON.

Usage

Here's some example usage of number keys as reference (the !! cont.root ! root container ! is a map with number typed keys): 

(&
26:: "value
26-12-08T12:30:: "value
