Definition

Number keys are !! key.typed ! typed keys ! that use !! val.num ! numbers ! to label values inside !! cont.map ! maps !.

They can be useful in many cases, such as when wishing to make a indexed list where not all items at all indexes are present, or where the indexes are seperate from the order in the list.

Number keys support any number, signed and with decimal points, in scientific notation and static numbers such as NaN and +/-Infinity.

Syntax

To write a number key, first, ensure the !! cont.map ! map ! has no specified key type declaration.

This means that, following the open parenthesis which declares the map, there is no symbol declaring the key type of the map. This is because the parser can recognize the key type directly by looking at the first key, which self-declares the map's key type.

Afterwards, write each key as a valid number, terminating the key with a colon : before writing the value associated to the key.

View !! val.num ! number value syntax ! to see how to write valid numbers in LXON.
