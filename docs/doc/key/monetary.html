Definition

Monetary keys are !! key.typed ! typed keys ! that use !! val.monetary ! monetary values ! to label other values inside !! cont.map ! maps !.

Syntax

To write a monetary key, first, ensure the !! cont.map ! map ! is set to use monetary keys. Do so by writing the declaration character after the open parenthesis, a dollar sign $.

If you wish to keep the currency unspecified (you can then optionnally specify a different currency per key), type a newline or asterisk * after the dollar sign.

Your monetary key type declaration with unspecified currency should look as follows: 

($*

If you wish to specify a currency homogeniously on all keys, add the currency code after the dollar sign. Terminate the code with either a newline or period ..

Your monetary key type declaration with specified currency should look as follows (use any currency code): 

($eur

Afterwards, write each key as a !! val.mon.syntax ! valid monetary value !, optionnally specifying a currency if it wasn't specified. Terminate the key with a colon : before writing the value associated to the key.
