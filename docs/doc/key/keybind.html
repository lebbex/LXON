Definition

Keybind keys are !! key.typed ! typed keys ! that use !! val.bind ! keybinds ! to label values inside !! cont.map ! maps !.

Syntax

To write a keybind key, first, ensure the !! cont.map ! map ! is set to use keybind keys. Do so by writing the declaration character after the open parenthesis, an at symbol @.

Your keybind key type declaration should look as follows: 

(@

Afterwards, write each key as a !! val.bind.syntax ! valid keybind !, terminating the key with a colon : before writing the value associated to the key. Do not terminate keybinds with any other terminator symbol, even if keybind values can be terminated with them. Those termination symbols will be parsed as content of the keybind. As such, you don't need to !! other.escape ! escape ! them either.

Usage

Here's some example usage of keybind keys as reference (the !! cont.root ! root container ! is a map with keybind typed keys): 

(@
up_arrow: "forwards
down_arrow: "backwards
left_arrow: "strafe left
right_arrow: "strafe right

miscelanious keybind: "value
symbols `^&$@#=/*?` : "value
