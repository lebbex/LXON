Definition

Color keys are !! key.typed ! typed keys ! that use !! val.col ! colors ! to label values inside !! cont.map ! maps !.

Syntax

To write a color key, first, decide which color space, gamma curve (default / linear) and precision level you want the color keys in the map to have. Color keys must be of homogenious type throughout the map.

Once you have it chosen, ensure the !! cont.map ! map ! is set to use correct key type. Do so by writing the full declaration character for the color type after the open parenthesis.

Here are the avaible color type declaration sequences (profiled color requires an additionnal color code between characters):

  • !! val.color.prec.8 ! 8 Bit Colors !:
    • sRGB Color #
    • Linear sRGB Color =
    • Profiled Color / with .
    • Linear Profiled Color / with -
  • !! val.color.prec.10 ! 10 Bit Colors !:
    • Profiled Color / with ,
    • Linear Profiled Color / with <
  • !! val.color.prec.12 ! 12 Bit Colors !:
    • Profiled Color / with :
    • Linear Profiled Color / with >
  • !! val.color.prec.16 ! 16 Bit Colors !:
    • sRGB Color ;
    • Linear sRGB Color ;=
    • Profiled Color / with ;
    • Linear Profiled Color / with =
  • !! val.color.prec.float ! Infinite Precision Colors !:
    • Profiled Color / with '
    • Profiled Linear Color / with ^

Your keybind key type declaration should look as follows (example uses !! val.col.prec.8bit ! 8bit ! !! val.col.space.srgb ! sRGB ! color): 

(#

Afterwards, write each key as a valid color for the chosen color type, terminating the key with a colon : before writing the value associated to the key.

View !! val.col ! color syntax ! to see how to write valid colors in LXON.

Usage

Here's some example usage of keybind keys as reference (the !! cont.root ! root container ! is a map with keybind typed keys): 

(@
up_arrow: "forwards
down_arrow: "backwards
left_arrow: "strafe left
right_arrow: "strafe right

miscelanious keybind: "value
symbols `^&$@#=/*?` : "value
