Definition

Enum keys are !! key.typed ! typed keys ! that use !! val.enum ! enums ! to label other values inside !! cont.map ! maps !.

Syntax

To write an enum key, first, ensure the !! cont.map ! map ! is set to use enum keys. Do so by writing the declaration character after the open parenthesis, an asterisk *.

If you wish to leave the enum type undefined, type a newline or a second asterisk after the first asterisk.

Your enum key type declaration with unspecified type should look as follows: 

(**

If you wish to specify an enum type homogeniously on all keys, write the enum type after the first asterisk, terminating the enum type with either a newline or colon :.

Your enum key type declaration with specified type should look as follows (use any enum type): 

(*weapon:

Afterwards, write each key as a !! val.enum.syntax ! valid enum !. Terminate the key with a colon : before writing the value associated to the key.

Usage

Here's some example usage of enum keys as reference: 

{
unspec1:(*
	gun: "value
	grenade: "value

unspec2:(**
	bread: "value
	sugar: "value

unspec3:(**cx7: `mazda` q5: "audi

map1:(*weapons
	gun: "value
	grenade: "value

map2:(*food:
	bread: "value
	sugar: "value

map3:(*cars:cx7: `mazda` q5: "audi
