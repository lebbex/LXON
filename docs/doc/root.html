Definition

The root container isn't a container type itself. The root container is, as the name implies, the main container that wraps all the data.

The most common root container to use is the !! cont.obj ! object !, and in certain cases the !! cont.arr ! array !. However, any container type can be used as the root container, including !! cont.map ! maps ! and !! cont.doo ! doodads !.

Syntax

To write any LXON file, you first need to instanciate a root container type. To do so, write, as the first character, the type declarator of the target container type. The symbol HAS to be the first character of the file, as many parsers won't trim preceding whitespace.

Here are the different type declarator options:

  • !! cont.obj ! Object ! {
  • !! cont.arr ! Array ! [
  • !! cont.map ! Map ! (

As you may notice, there is no type declarator for !! cont.doo ! doodads !. That is because a doodad is the catch all exception, the else condition if no declarator symbol was used (or if it wasn't the first character).

Usage

!! cont.obj ! Object !

Here's example usage of an object as root container: 

{
id: 92
name: "Malcom
male: $
home:
    Country: "USA
    State: "Pennsylvania
    City: "Pittsburgh
    N.H.: "Point Breeze
albums:[
    "Swimming
    "Circles

!! cont.arr ! Array !

Here's example usage of an array as root container: 

[
96
"Gustav
$
{
    Country: "USA
    State: "New York
    City: "Long Beach
    N.H.: "West End
[
    "PART ONE
    "LIVE FOREVER

!! cont.map ! Map !

Here's example usage of a map as root container: 

(*field:
id: 93
name: "Jahron
$
home:
    Country: "Canada
    Province: "Ontario
    City: "Mississauga
    N.H.: "Applewood
albums:[
    "TWO
    "4
